FolderSync v1.1 - Changelog
============================

Release Date: 2026-02-09

NEW FEATURES
------------

1. Auto-Search for Folders
   - Added "🔍 Find 'tools'" button to automatically search C:\ for folders named "tools"
   - Added "🔍 Find Other..." button with enhanced custom search:
     * Browse to select starting search path (not limited to C:\)
     * Enter custom folder name to search for
     * Both fields in one convenient dialog
   - Smart search strategy:
     * When searching C:\ - uses focused search in common locations for speed
     * When searching specific paths (e.g., C:\ToolSnap) - searches that path directly
   - Search depth: 3 levels max for speed
   - Results presented in checklist dialog with Select All/Deselect All options
   - All found folders pre-selected for quick batch import
   - Results displayed in larger 14pt font for better readability

-------

Files Modified:
- gui.py: Added search buttons, custom path+name dialog, handler methods (+108 lines, now 1051 lines)
- scanner.py: Added search_folders_by_name() with smart search strategy (+95 lines, now 237 lines)

Files Added:
- dialogs.py: New module for folder search dialog (196 lines)
- start_FS.bat: Windows launcher script

USAGE
-----

Method 1 - Find 'tools' Folders:
1. Click "🔍 Find 'tools'" button
2. Wait 5-15 seconds while app searches C:\
3. Select which folders to add (all pre-selected)
4. Click "Add Selected"

Method 2 - Find Other Named Folders (Enhanced):
1. Click "🔍 Find Other..." button  
2. Enter starting search path (or browse to select) - default is C:\
   - For specific folders like C:\ToolSnap, searches directly in that location
   - For C:\, uses optimized search in common locations
3. Enter folder name to search for (e.g., "utils", "scripts", "bin")
4. Click "Search"
5. Wait for search to complete (faster for specific paths)
6. Select which folders to add from results
7. Click "Add Selected"

After adding folders, click "Compare" to see conflicts.

TECHNICAL NOTES
---------------

Search Algorithm - Smart Strategy:
- When searching C:\ root:
  * Uses focused search in common locations (auto_trading, Users, projects, dev, code, workspace, Documents, development, repos, src)
  * Max depth: 3 levels below each common location
  * Typical time: 5-15 seconds
  
- When searching specific paths (e.g., C:\ToolSnap, C:\projects):
  * Searches that path directly
  * Max depth: 3 levels from specified path
  * Much faster: typically 1-3 seconds
  
- Both strategies:
  * Skip empty folders (must have subdirectories)
  * De-duplicate symlinks via path resolution
  * Handle permission errors gracefully

Performance:
- C:\ search: 5-15 seconds (searches multiple common locations)
- Specific path search: 1-5 seconds (focused search)
- Can still add folders manually if search misses any

UI Improvements:
- Search results displayed in 14pt font for better readability
- Custom search dialog provides both path and name inputs
- Browse button for easy path selection

KNOWN LIMITATIONS
-----------------

- Max search depth: 3 levels to avoid performance issues
- When searching C:\, only searches common locations (not exhaustive scan)
- Use manual "+ Add Folder" for any missed locations

EXAMPLES
--------

Search C:\ToolSnap for 'tools' folders:
1. Click "🔍 Find Other..."
2. Search in: C:\ToolSnap (type or browse)
3. Folder name: tools
4. Click Search
→ Finds C:\ToolSnap\tools and any 'tools' folders up to 3 levels deep

Search entire C:\ for 'utils' folders:
1. Click "🔍 Find Other..."  
2. Search in: C:\ (default)
3. Folder name: utils
4. Click Search
→ Searches C:\auto_trading\*\*\utils, C:\Users\*\*\utils, C:\projects\*\*\utils, etc.
